Plain Style
a Puritan reading library

Read the Puritans as they wrote, and as we'd write it now.

Each work here is shown in its original English, set beside a modernized text. Where the original is dense or unfamiliar, the modern text is there to help — but the original stays in view, so nothing is taken on faith.

Every reader has a toggle for how far the modernization goes: a lighter, close-to-the-original rendering, or a fuller rewrite into plain contemporary English.
